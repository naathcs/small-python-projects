## How to Run

Download the file `wordGuessing.py`.

Open your terminal and find the where the `wordGuessing.py` file was downloaded, then follow the steps below.

```
# (Optional)Create a Virtual Environment
python3 -m venv venv
```
```
# (Optional)Active Virtual Environment
source .venv/bin/activate
```
```
# Run the Code
python3 wordGuessing.py
```

**NOTE:** The code will NOT run on the terminal, a window with the GUI application will open instead.
