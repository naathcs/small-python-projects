## How to Run

Download the file `10-password-strength-checker.py`.

Open your terminal and find the where the `10-password-strength-checker.py` folder was downloaded, then follow the steps below.

```
# Create a Virtual Environment
python3 -m venv venv
```
```
# (Optional)Active Virtual Environment
source .venv/bin/activate
```
```
# Install the library used in this application in your virtual machine
pip install password-strength
```
```
# Run the Code
python3 10-password-strength-checker.py
```

**NOTE:** The code will NOT run on the terminal, a window with the GUI application will open instead.
