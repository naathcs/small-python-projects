#### How to Run

Open the terminal and find the folder where the Python file was downloaded, then follow the steps below.

```
# Create a Virtual Environment
python3 -m venv venv
```
```
# Active Virtual Environment
source .venv/bin/activate
```

If not installed already, follow this step
```
# (OPTIONAL) Install Currency Converter
pip3 install currencyconverter
```
